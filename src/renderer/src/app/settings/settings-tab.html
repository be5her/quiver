Agent permissions

Commands that only read are open to agents; the mode decides what commands that delete, write or change shared state get. Rules come first: a command id (db.query.run), a module (git.*) or *. A deny anywhere wins and hides the tool from agents, then the most specific rule, workspace rules before these. The command line and this window are you, so none of this applies to them.
