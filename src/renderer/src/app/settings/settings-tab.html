Agent permissions

Commands that only read are open to agents; the mode decides what commands that delete, write or change shared state get. Rules come first: a command id (db.query.run), one action of it (db.query.run#ddl, for the tools that say what a call does), a module (git.*) or *, for every agent or one by name. A deny anywhere wins (on a whole tool it hides the tool from agents), then the most specific rule (an action before its tool, a rule for the agent before one for every agent), workspace rules before these. The command line and this window are you, so none of this applies to them.
